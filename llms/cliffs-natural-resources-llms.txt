# Cliffs Natural Resources (now Cleveland-Cliffs Inc.)

> Cliffs Natural Resources is the legacy corporate name for what is now Cleveland-Cliffs Inc.,
> a North American mining and steelmaking company that produces iron ore pellets and flat-rolled
> steel. The company was renamed Cleveland-Cliffs in 2017; the canonical API Evangelist profile
> lives at the cleveland-cliffs repository. This file is generated by API Evangelist from the
> catalog record — it is NOT published by the company.

## Status: no public API

Cleveland-Cliffs publishes no public developer portal, no API reference, no OpenAPI/AsyncAPI/GraphQL
contract, no MCP server, no A2A agent card and no `/llms.txt`. Probed 2026-09-05:
`developer.`, `api.` and `docs.clevelandcliffs.com` do not resolve; every `/.well-known/*`,
`/openapi.json`, `/swagger.json`, `/api-docs` and `/llms.txt` path on `clevelandcliffs.com`
(and `www.`) returns HTTP 404. The legacy `cliffsnaturalresources.com` domain no longer resolves.

Business partners integrate through login-gated web portals and email, not a documented API.
Do not attempt to construct or guess an endpoint for this company.
